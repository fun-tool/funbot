# FunBot

本地运行的 Anubis 主网多钱包竞技场工具。一个主号管理多个子号，主号也可以参赛。

**下载源码 → 编译程序 → 放进账号组文件夹 → 导入钱包 → 启动与设置**

**只看适合自己电脑的一节，完成后继续「页面操作」。** 每条命令复制后按回车，等执行完成再进行下一步。

## Windows 教程

**1. 下载并解压源码**

打开 [fun-tool/funbot](https://github.com/fun-tool/funbot)，点击 **Code → Download ZIP** 。右键下载的 ZIP，选择“全部解压”。

打开解压后的源码文件夹，以能直接看到 `go.mod`、`main.go` 和 `public` 为准；文件夹名称以实际下载结果为准。

**2. 打开命令行**

在源码文件夹顶部的 **地址栏** 输入 `powershell`，按回车。不要输入到右侧搜索框。

![打开命令行：Windows 在文件夹地址栏输入 powershell；Mac 打开终端并拖入文件夹](docs/images/open-terminal.png)

**3. 安装 Go**

```powershell
winget install --id GoLang.Go --exact --source winget
```

安装完成后关闭 PowerShell，按第 2 步重新打开，检查版本：

```powershell
go version
```

需要 **Go 1.26.8 或更高版本** 。如果找不到 `winget`，到 [Go 官网](https://go.dev/dl/) 下载 Windows 安装包，双击安装。普通 Intel / AMD 电脑选 `windows-amd64.msi`，ARM 电脑选 `windows-arm64.msi`。

![安装 Go：Windows 用 WinGet，Mac 用 Homebrew 或官方安装包，重新打开命令行检查版本](docs/images/install-go.png)

**4. 编译**

在能看到 `go.mod` 的源码文件夹中执行：

```powershell
go build .
```

`.` 表示编译当前目录。第一次会下载依赖；命令执行完且没有报错，回到文件夹查看新生成的程序。

**找到新增的 `funbot` 应用程序** ，类型为“应用程序”，不用改文件名。拖动的是这个程序文件。

**5. 建立账号组文件夹**

在桌面新建一个文件夹，例如 **账号组A** 。用鼠标把刚编译的 **`funbot`** 拖进去即可，网页已包含在程序中，不用搬源码和 `public`。

打开“账号组A”，在顶部地址栏输入 `powershell`，回车。 **后面的命令都在这个新文件夹里执行。**

![Windows：编译得到应用程序，再拖入账号组文件夹](docs/images/windows-terminal.png)

**6. 导入主号**

```powershell
.\funbot -add master
```

按提示： **设置密钥文件密码 → 输入助记词或私钥 → 核对地址 → 输入 `y` → 填写备注** 。密码至少 8 位，以后解锁继续使用它；看到“已加入”才算成功。

输入密码、助记词、私钥时不显示内容，也没有星号，这是正常的。

同一组助记词的子号，进入页面后派生即可。 **如果子号使用另一组助记词或单独的私钥，再执行：**

```powershell
.\funbot -add member
```

输入原密钥文件密码，再输入子号的助记词或私钥。可连续导入多组，全部完成后空行回车结束。每组助记词先导入第 0 个地址，其余地址进入页面后派生。

每个账号组只有一个主号；添加子号使用 `member`，不用重复导入主号。

![导入主号后按子号来源选择：同一助记词在页面派生，另一助记词用 member 导入](docs/images/import-wallet.png)

**7. 启动程序**

```powershell
.\funbot
```

浏览器会自动打开。保留 PowerShell 窗口，接着按下方 [页面操作](#页面操作) 完成设置。

## 页面操作

Windows 和 Mac 操作相同，按下面顺序完成。

**解锁 → 派生子号 → 部署或载入合约 → 委托 → 加入名册 → 拜师授权 → 开跑**

![页面准备总览：解锁、派生、连接个人合约、参赛设置、委托、入册、授权与开跑](docs/images/first-run.png)

### 1. 解锁

打开“设置”，输入导入时设置的密钥文件密码，点击“解锁”。确认显示“主网”，并核对主号地址。

浏览器没有自动打开时，复制终端打印的 **完整本地链接** 到浏览器，保留末尾的 `?t=...`。每次启动使用当次的新链接。

![启动与解锁：在账号组文件夹运行 funbot，用本次完整链接打开页面并输入密钥密码](docs/images/launch-unlock.png)

### 2. 派生子号

进入 **设置 → 从已保存的助记词派生钱包** ，选择要使用的助记词组。

例如主号与子号来自同一组助记词，要组成“1 个主号 + 23 个子号”，填写：

| 字段 | 填写内容 |
| --- | --- |
| 助记词组 | 主号所在的助记词组 |
| 起始序号 | `1` |
| 派生数量 | `23` |
| 新钱包备注前缀 | 例如“队员” |
| 密钥文件密码 | 导入时设置的密码 |

点击 **“派生并加密保存”** 。第 0 个地址已导入为主号，这次新增第 1～23 个地址。

子号来自另一组助记词时，选择之前用 `-add member` 导入的那一组。它的第 0 个子号已存在；例如还需 23 个子号，同样从 `1` 开始派生 `23` 个。

**页面不需要输入助记词。单个私钥不能派生；只导入了私钥的账号可直接继续下一步。**

![派生示例：已存在主号序号 0，从 1 开始派生 23 个子号，共 24 个账号](docs/images/derive-wallet.png)

### 3. 部署或载入合约

主号先准备足够的 **本链 Gas 币** 。部署需要 Gas，游戏入场使用 fLGNS，两者用途不同。

在“设置 → 合约”：

- **第一次使用：** 在“新部署一个”处填写符合游戏要求的师父地址，点击“部署”，核对确认提示，等待日志显示成功。
- **已有合约：** 填写这个主号对应的 Squad 地址，点击“载入”，无需重复部署。

师父栏留空时使用主号作为师父，主号必须满足游戏的师父资格。 **拜师关系绑定后不能更改，请先核对地址。**

部署成功后合约地址自动保存。“合约”栏填个人 Squad 地址，不是游戏 Arena 或代币地址。

![首次部署填写合格师父地址，已有个人 Squad 合约则直接载入](docs/images/deploy-contract.png)

### 4. 选择主号是否参赛

在“参赛设置”中设置 **“主号参加比赛”** ：

- 勾选：主号与子号一起参赛，放在第一组最前面。
- 不勾选：主号只负责支付 Gas、补币和收款，单独显示在最上面。

设置自动保存。账号按顺序每 24 个一组，最后一组可以不足 24 个。

### 5. 委托、加入名册、拜师授权

在“账号设置”勾选要使用的账号，可以选本组、跨组选中，或输入范围，例如 `5` 到 `15`（共 11 个）。

依次点击，每一步都等日志确认成功再继续：

| 顺序 | 按钮 | 用途 |
| --- | --- | --- |
| ① | 委托选中账号 | 完成 EIP-7702 委托，由主号支付 Gas |
| ② | 选中账号加入名册 | 把要参赛的账号加入链上名册 |
| ③ | 拜师 + 授权 | 完成游戏需要的准备 |

主号尚未委托时，第①步会自动一并处理。主号要参加比赛，第②步还需勾选主号并开启参赛设置。第③步处理选中的名册账号。

**导入或派生只保存本地钱包；以后新增账号，也要完成这三步。**

![勾选账号后依次完成委托、加入名册、拜师授权，每步等待日志确认](docs/images/prepare-accounts.png)

### 6. 开始打局

切换到“跑”，选择账号、场数和入场方式，再点击“开跑”。

| 入场方式 | 含义 |
| --- | --- |
| 能打就打 | 能入场的先打；选择 1 场时处理一批后结束，不等待占位账号补打 |
| 等齐再打 | 等整批选中账号模拟通过再提交，可能需要等待；不代表全部进入同一个局号 |

场数表示每个号 **再打最多多少场** ，仍受当天最多 12 场限制。查看执行日志中的实际入场数量；不要仅凭按钮点击判断成功。

入场优先使用足够的已结算擂台回款。回款不够时从钱包支付，子号钱包不足由主号补差额。 **未结算押金不能直接当作可用余额。**

需要提前给子号转币时，填写每人金额，点击“批量转入”。例如选 3 个子号、填写 `100`，就是各增加 100，共转入 300；主号自动跳过。

“盟主次数”单独一列显示该地址累计已裁决的胜出次数，读取失败显示“—”。

![选择账号、场数和入场方式后开跑，以日志确认的实际入场数量为准](docs/images/play-game.png)

### 7. 手动领取与归集

勾选要收款的账号，点击 **“领取收益并归集”** ：领取甲子俸、师徒收益、可领取的擂台回款，再把可用 fLGNS 转给主号。未结算押金需要满足合约条件后才能收回。

打局不会自动归集。“收 gas 币”是另一项操作，使用前核对选中账号和确认提示。

![归集流程：选中账号，领取甲子俸、师徒收益和可领取擂台回款，再转给主号](docs/images/collect-funds.png)

## 多组账号管理

**编译一次，在桌面建立多个文件夹，把编译好的程序分别复制进去。** 例如“账号组A”“账号组B”“账号组C”。

每个文件夹只需要一份程序。把 `funbot` 程序用鼠标复制、粘贴进去即可。

在各自文件夹打开命令行，分别导入对应的主号和子号，再启动。 **首次启动程序或执行导入命令时，会自动在程序旁边创建 `.data`，不用手动建立。** 首次成功导入钱包后，才会生成 `.data/keys.json`；合约地址和设置也保存在本组的 `.data` 中。

| 账号组A | 账号组B |
| --- | --- |
| 一份编译好的程序 | 一份编译好的程序 |
| A 的主号与子号 | B 的主号与子号 |
| A 自己的 `.data` | B 自己的 `.data` |

**创建新账号组只复制程序，不复制其他账号组的 `.data`。** 复制 `.data` 会复制同一套钱包，不会产生新的账号。

可以同时运行多个账号组；每个保留自己的终端窗口，并使用对应窗口打印的网页链接。默认端口被占用时程序会自动换端口，打开后核对主号。

![多组账号独立保存：把程序复制到账号组 A、B、C，分别导入钱包，各自产生 .data](docs/images/account-groups.png)

## 日常使用

**再次启动**

在对应的 **账号组文件夹** 打开命令行，按系统启动：

Windows：

```powershell
.\funbot
```

Mac：

```sh
./funbot
```

用本次链接打开页面并解锁即可，无需再次编译、导入或重复部署。

**退出与备份**

退出时先停止批量任务，查看有无待确认交易，再在终端按 `Ctrl + C`。关闭网页不会停止程序，已经广播的交易也不会因退出而撤销。

**钱包与设置保存在程序旁边的 `.data`，退出后备份整个 `.data`。** Windows 可在账号组文件夹地址栏追加 `\.data` 打开；Mac 在访达按 `Command + Shift + .` 显示隐藏文件。

**更新与搬家**

更新：下载新源码 → `go build .` → 退出旧程序 → 用新程序替换各账号组的旧程序，保留各自的 `.data`。

搬家：退出程序后，移动整个账号组文件夹。换到不同系统或芯片的电脑时，需要在新电脑重新编译程序，再迁移 `.data`。

![备份整个 .data，更新只换程序，搬家移动整个账号组文件夹](docs/images/backup-data.png)

## 常见问题

| 问题 | 怎么处理 |
| --- | --- |
| 找不到 `go` | 安装 Go 后关闭旧命令行，重新打开，执行 `go version` |
| 提示 Go 版本太旧 | 安装 Go 1.26.8 或更高版本，重新打开命令行后检查 `go version` |
| 编译找不到 `go.mod` | 进入能直接看到 `go.mod`、`main.go`、`public` 的源码文件夹，再执行 `go build .` |
| 一直显示 `downloading` | 首次在下载依赖，先等待；网络超时后检查网络，再重试编译命令 |
| 找不到编译好的程序 | 回到源码文件夹查看：Windows 找 `funbot` 应用程序，Mac 找 `funbot` 可执行文件 |
| 移动程序后命令找不到文件 | 重新在账号组文件夹打开命令行，不能继续停留在原源码目录 |
| 输入密码没有反应 | 输入内容不回显，填完按回车；不要重复粘贴 |
| 密码不对 | 已有钱包要用原密钥文件密码，不是设置一个新密码 |
| 网页打不开或令牌错误 | 使用本次启动打印的完整链接，包括 `?t=...`，并保持终端运行 |
| 部署或准备失败 | 查看执行日志，检查本链 Gas、师父资格和账号准备状态 |

更多说明：[钱包导入、Git 更新、取消委托、裁决规则与代码审核](docs/REFERENCE.md)。

## 安全与许可

助记词和私钥只在终端提示处输入， **不要写在命令后面、粘贴到网页或发到 Issue** 。网页派生使用本机已加密保存的助记词。妥善保存密钥文件密码和原始钱包备份。

本工具会签署主网交易，需要保护电脑和主号。源码公开与本地加密不代表没有风险。
