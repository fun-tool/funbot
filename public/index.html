从打开命令行到启动、导入账号

按 README 执行 go build .，把生成的 funbot 放进账号组文件夹。以下命令都在账号组文件夹运行。

1. 打开终端并进入程序文件夹

按 Command + 空格，搜索「终端」并打开。在终端输入 cd （后面留一个空格），从 Finder 把账号组文件夹拖进终端，然后按回车。

拖文件夹，不是拖程序文件；路径中的空格会自动处理。

2. 启动程序

保持终端开着，程序会打开本地网页。如果已经打开本页，无需重复启动；未自动打开时，复制终端显示的完整链接到浏览器。

3. 再开一个终端窗口，导入账号

按 Command + N 新建终端窗口，再按第 1 步进入同一个程序文件夹。首次导入设置密钥文件密码，后续使用同一个密码。

1. 在程序文件夹打开 PowerShell

在文件资源管理器中打开存放 funbot 的账号组文件夹。点击上方地址栏，输入 powershell 并按回车，打开的命令行就位于这个文件夹。

2. 启动程序

保留命令前的 .\，并保持窗口开着。已打开本页时无需重复启动；未自动打开时，复制终端显示的完整链接到浏览器。

3. 再开一个 PowerShell 窗口，导入账号

在同一个程序文件夹的地址栏再次输入 powershell 并回车。首次导入设置密钥文件密码，后续使用同一个密码。

4. 按提示输入，再回网页解锁

  1. 在终端粘贴助记词或私钥，再按回车。输入内容不回显；提交后显示单词数或私钥位数。
  2. 核对程序显示的钱包地址，输入 y 确认，再填写备注。
  3. 连续导入队员时，每次输入一条助记词或私钥；空行回车结束。
  4. 回到网页，点「重新读取账号」并解锁。需要同一助记词的更多钱包时，在下方派生。

下次只需进入程序文件夹、执行第 2 步启动，再到网页解锁。退出程序用启动窗口里的 Ctrl + C。
